# Changelog

## [0.12.0](https://github.com/PolusAI/nyxus/compare/nyxus-v0.11.0...nyxus-v0.12.0) (2026-10-29)


### ⚠ BREAKING CHANGES

* **binning:** 3D GLRLM, GLSZM, GLDM and NGTDM now bin at the coarse grey depth, so their default output moves from unbinned raw levels to 64 MATLAB-style levels. Pass --coarseGrayDepth=0 (coarse_gray_depth=0 in Python), or set 3<family>/greydepth=0 for one family, to get the previous unbinned output. Python's set_params() and set_environment_params() now raise ValueError for a coarse_gray_depth other than the object's current one; pass a different depth to the constructor.
* **omezarr:** OME-Zarr support now requires z5 3.0.1 and C++20; xtensor/xsimd are no longer used.
